# Apple M4 上的 Breeze-ASR-25 MLX 與 mm2t 現行版本

2026 年 11 月 19 日，Apple M4、32 GB。mm2t 的模型資料夾內有 AudioEncoder.mlmodelc、TextDecoder.mlmodelc；專案指定 WhisperKit 1.1.1 與 Core ML 4-bit palette 權重。MLX 兩版以 mlx-whisper 0.4.3、MLX 0.32.4 在本機 GPU 實際辨識。測試錄音均留在本機。

| 版本 | 模型來源與固定版本 | 本輪模型準備 |
|---|---|---:|
| mm2t Core ML 4-bit | [weiren119，3fc1623](https://huggingface.co/weiren119/Breeze-ASR-25-coreml-4bit-palette/tree/3fc162355f3460de6b1e53518a1678cea06464d9) | 90.60 秒，另一次程序 74.34 秒 |
| MLX FP16，權重 3,083 MB | [schsu，6e48985](https://huggingface.co/schsu/breeze-asr-25-mlx/tree/6e48985d562fcf19e80daf8bebf84fb994fb3cc7) | 3.11 秒 |
| MLX 4-bit，權重 877 MB | [david20571015，c4dcbfd](https://huggingface.co/david20571015/Breeze-ASR-25-mlx-q4/tree/c4dcbfd97e22029060ae01f34aec53943af33e71) | 0.97 秒 |

準備時間從呼叫已安裝的引擎載入已下載權重算起，MLX 在 GPU 同步後停表。排除下載及程序啟動，各次檔案與系統編譯快取狀態未控制。兩種 4-bit 的量化方法也不同。
